#__Инструкция по запуску и установке__

1. Установите все необходимые зависимости, указанные в файле requirements.txt. 2
2. Выполните миграции базы данных командой:

'python3 manage.py migrate'

3. Создайте файл конфигурации окружения, скопировав и заполнив .env.sample, затем переименуйте его в .env.
4. Запустите команду создания супер-пользователя:

'python manage.py csu'

5. Соберите Docker-образ и запустите контейнер:

'docker compose up --build -d'

6. Запустите локальный сервер разработки:

'python manage.py runserver'

7.  Откройте браузер и перейдите по адресу http://127.0.0.1:8000, чтобы начать работу.
8.  Для полноценного управления содержимым и пользователями войдите в административную панель по адресу /admin под учетной записью администратора и настройте базу данных.
